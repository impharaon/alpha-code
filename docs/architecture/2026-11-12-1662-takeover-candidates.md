## Bottom line

- **1 clear TAKE OVER**, and it extends a takeover that already exists: move the session-scoped "always" for approvals into `core/src/permission.ts`.
- **2 wins that need no takeover at all.** Existing hooks already give what the workarounds rebuild: the directory-read card can be built in ext `execute.after` from structured output, and project skill directories can be loaded through upstream's own `SkillFile.parse`.
- Every other seed is KEEP WORKAROUND or ASK UPSTREAM. In each case the workaround is pinned by a test that would fail if upstream changed, or upstream itself defines the pattern (for example "clients poll"), or the replacing files are hot (`config.ts` 32 commits, `internal.ts` 58, `model-request.ts` 63, `session.ts` 52).
- Opposite direction: none of today's 6 takeovers can be replaced by a hook outright. `to-session-error.ts` *might* be replaceable by a Code Puppy `ServerOptions.fetch` wrapper; that needs a probe. One build-time source rewrite is a takeover in all but name and is missing from the takeover list.
