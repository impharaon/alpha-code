组件库缺的一块:名称 — 值卡片

停在这里

  • 组件库里有的:Button、Input、Dialog、Toast、Tooltip、Banner(system/components.md 与 gallery.html 只有这六个)。没有卡片、分区、名称 — 值一行。
  • 应用里各自做了至少五套:账户弹层余额卡、设置页分组与行、定制中心详情页事实行、能力授权框能力列表、批准面板「将记住」框。都是浅边框 + 大圆角 + 一行一项,细节各不相同 —— 就是「每张卡片自己做一套」。
  • 提议:把账户弹层那张余额卡收进组件库,叫「名称 — 值卡片」:卡片(--a-bg-subtle 底、--a-border-faint 边、--a-radius-lg、内边距 12)+ 行(名称 --a-text-secondary 在左,值 600 字重在右)。它已经在显示同样的余额和额度,用户在两处看到的是同一张卡。弹层改用它后样子不变;去掉的只有弹层专用的左右外边距。
