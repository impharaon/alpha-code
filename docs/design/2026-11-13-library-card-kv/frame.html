卡片 与 名称 — 值列表

两个组件:「卡片」把一组只读的事实框在一起;「名称 — 值列表」一行一项,名称在左、值在右。账户弹层和两种云端发送框共用它们,以后别处要放同类东西也用它们,不再各做一套。

与上一稿的关系

  • 来源:账户弹层的余额卡(account-popover.css 的 .codepuppy-acct-card / -row / -k / -v / -pending)。owner 2026-11-13 定:收进组件库,弹层和发送框共用;组件库没有的标准先设计组件,再使用。
  • 不是改个名字:弹层的写法里有写死的数值(12.5px、3px、11px、600)和弹层专用的外边距。组件只用令牌,外边距交给放它的地方,名称和值换成 <dl> / <dt> / <dd>,读屏能读出「名称:值」。
  • 只做现在用得到的:卡片一个样子,列表一个尺寸;值有三种状态(有值 / 读取中 / 读不到),都是弹层今天已经有的。

卡片 .a-card

做什么把一组只读的事实框成一块,和周围内容分开。
组成只有外框。里面放一个名称 — 值列表(现在只有这一种用法)。
变体 / 尺寸各一种。
样子底 --a-bg-subtle,边 1px --a-border-faint,圆角 --a-radius-lg,内边距 --a-space-3(12)。宽度跟放它的容器;自己不带外边距。
状态只有静态。不可点、不可聚焦,没有悬停。
读屏外框本身不读;需要名字时由放它的地方给 aria-label。
要放 2–6 项只读事实;放在它说明的那件事旁边。
不要在卡片里放按钮、开关或输入;卡片套卡片;用它放提示或报错(用提示条 Banner)。
按钮放哪和卡片内容有关的动作放在卡片之后、所在区域的按钮行里,靠右(同组件库对话框底栏 .a-dialog-footer 的 justify-content: flex-end)。卡片自己没有按钮位。

名称 — 值列表 .a-kv / .a-kv-row

做什么一行说一件事:名称 + 它现在的值。
组成<dl class="a-kv"> → 每行 <div class="a-kv-row">,里面 <dt class="a-kv-k"> 名称 + <dd class="a-kv-v"> 值。值可以是文字、数字或一个小图(弹层的 14 天走势)。
变体 / 尺寸各一种。
样子字号 --a-text-sm,行高 --a-leading-snug,上下内边距 --a-space-1,名称和值至少隔 --a-space-3。名称 --a-text-secondary;值 --a-text、--a-weight-semibold、靠右、等宽数字。行与行之间没有分隔线。
值的状态有值;读取中写「…」;读不到写「—」。后两种用 --a-text-tertiary、--a-weight-medium、--a-text-xs(弹层今天的写法)。
读屏dl/dt/dd 读成「名称,值」。「…」「—」读出来没有意义:实现时给这两种值加只给读屏的文字「正在读取」「暂时读不到」。
要名称短(不超过 10 个字);数字带千分位;同一列表里同类值用同一写法(如「用量 / 上限」)。
不要值里放按钮或开关;名称写成一句话;用它排列可点的条目(那是列表行,不是事实)。
窄的时候名称不换行;值太长时值换行、仍靠右。

哪里改前改后

能否收编应用里另外四套只核对,这次不重画

现有那一套和新组件不同的地方以后收编要加什么
设置页 分组 + 行
.codepuppy-settings-group/-row		白底(--a-surface)带轻阴影;有标题栏;行之间有分隔线;行高至少 58;左边是标题 + 一行说明,右边是开关或按钮(可操作)卡片加一个「白底 + 标题栏 + 分隔线」变体;行是「设置行」,不是名称 — 值(右边是控件)—— 另一个组件
定制中心详情 事实行
.codepuppy-ext-dfact		没有外框;名称占固定 96 宽一列,值紧跟在后面靠左;基线对齐名称 — 值列表加「两列靠左」排法,或把详情页改成值靠右(样子会变,要 owner 看)
能力授权框 能力列表
.codepuppy-ext-authz-box		透明底;行之间有分隔线;每行是图标 + 两行名称 + 技术名 + 标签,已授权行整行变淡外框可以用卡片(加「透明底 + 分隔线」);行是列表条目,不是名称 — 值
批准面板「将记住」框
.a-permission-remember		白底;顶部一条灰底标题栏;正文是一句话 + 一行小字,不是名称 — 值卡片加「标题栏」变体即可装下;不用名称 — 值列表

结论:卡片的外框四套都装得下,差的是「白底」「标题栏」「分隔线」三样,等真要收编时再加;名称 — 值列表只适合详情页事实行,另外三套的行是可操作的条目或一句话,不该硬套。
