# 桌面端界面优化:现状审查(2026-11-18)

## 给 owner 的总结

你点名的十二处(I-01…I-12)在实机上都能复现,根子是三件事:**没有统一的版面骨架**(顶栏只在会话页有,定制中心、自动化、设置各用一套页头,定制中心还叠在会话顶栏下面)、**强调色被当成选中底到处用**(侧栏当前对话、右栏页签、「+」菜单首项都是淡紫胶囊),以及**列表靠方框和按钮堆出层次**(连接器每行一个外框加实心或描边「添加」)。

你没点名、但同样影响观感的,按严重度排:

1. **文字里的工程话与半角标点**:界面字符串 2224 条里 310 条在中文旁用了半角「, : ; ? (」,另有 259 条用全角,两种混排;界面上直接出现 `allow / ask / deny`、`模式 all`、`Local Server`、`24k tokens`、`KEY`、英文的助手说明(`The default agent. Executes tools…`)。
2. **批准卡「期限」直接显示 `2026-11-18 08:03:34.951Z`**(ISO 时间原文),卡里再套两个灰框。
3. **继承自上游的错误页**:打开一个不存在的对话,显示「找不到此会话 / Local Server / ses_… / 关闭标签页」——Code Puppy 没有标签页。
4. **弹层只会向上开、不避让窗口边**:推理强度按钮打开的卡片顶部被窗口裁掉(提示语只露出半行)。
5. **一处功能、三个名字**:默认工作区在输入框下写 `code-puppy`、菜单里写「Code Puppy 默认工作区」,侧栏同时写「暂无项目」;首次引导卡用的是「α」方块而不是小狗图标。
6. **深色主题三列分不开**:画布 `#0a0b0d` 与侧栏 `#0e0f11` 对比约 1.03:1,侧栏边界几乎看不见;首页的发光在深色下是一团灰雾。
7. **搜索框两处、选中样式四种、页头四套**:有项目时侧栏同时有「搜索」一行和「搜索项目 / 会话…」输入框;对话搜索弹窗的输入框有两层焦点框。

改法全部是视觉与文字层面的,不加功能、不加步骤、不改安装与批准流程;方向样张见 `frame.html`。

## 怎么看的

- **版本**:worktree `design/2026-11-18-ui-refresh`,基于 `origin/alpha` `4cc001ac84`(Code Puppy 0.2.2)。
- **实机**:`electron-vite build` 后按可执行路径启动开发版,`OPENCODE_TEST_ONBOARDING=1`(独立临时数据根、内存数据库)加 `--use-mock-keychain`(不碰钥匙串),经调试端口驱动与截图,窗口始终在后台;结束后已从 LaunchServices 注销本次启动的 Electron 副本并删除临时数据根。截图 1440×900,在 `screenshots/current/`,下文写编号。
- **到不了的地方与替代**:隔离环境没有登录、没有可用模型(不用 owner 凭据;应用不接受本机地址的自定义服务,也不向第三方发请求),所以**发不出真实对话**。会话页的顶栏与右栏,用应用自己的引擎接口在内存库里建空对话后打开(30–34);时间线的消息、工作过程、批准卡、运行中状态,用仓库自带的视觉 harness(`packages/ui-mac/test-visual`,挂真实组件与真实 CSS,只桩数据)渲染(40–42)。账户余额卡、已登录状态、真实工具卡、扩展包的管理页没有走到,未列入。
- **现行视觉系统**:读 `packages/ui-mac/src/renderer/codepuppy-ui/tokens.css` 与侧栏、首页、输入框、会话工作区、定制中心、自动化、设置七份 CSS 统计。

**不一致**(逐项可在代码里找到):

1. **绕过令牌的原始数值**:上述七份 CSS 里写死字号 52 处(11px ×10、11.5px ×10、13px ×7、10px ×5、12.5px ×4、12px ×3、13.5px ×3、15px ×2、10.5px ×2、9px、19px、88px)、圆角 60 处(6px ×14、5px ×10、8px ×8、10px ×8、7px ×5 等)、十六进制颜色 73 处(定制中心 28、输入框 21)。
2. **不在阶上的值**:字号 9 / 11 / 12 / 13.5 / 15 px 与圆角 5 / 7 / 10 px 都不在令牌阶上。
3. **兜底色与令牌不符**:`var(--a-warning, #b45309)`(令牌是 `#d97706`)、`var(--a-success, #2f9e63)`(令牌是 `#16a34a`)一类共 11 处(`extension-hub.css`、`codepuppy-composer.css`)。
4. **一支强调色变成三支蓝**:填充靛蓝 `#4f46e5`、发送键 `#6366f1`、用户气泡蓝与信息蓝;选中底又是淡紫。
5. **选中样式四种**:侧栏当前对话 = 淡紫底 + 紫字 + 左侧竖条(`sidebar.css` `.codepuppy-session[data-active]`);当前项目 = 灰底 + 加粗;侧栏入口 = 灰底;右栏页签与「+」菜单焦点 = 淡紫胶囊(`session-workspace.css` `.a-swk-rail-tab--on`)。
6. **英文式小标题**:`text-transform: uppercase` + 字距 11 处(定制中心 6、首页弹层标签、设置、权限框、会话区),中文界面出现「AGENT」「CODE PUPPY 云」「KEY」。
7. **图标混用**:SVG 线性图标(1.6 线宽)与文字符号 `⊕ ⚙ ? ↑ ▾ ›` 混排(账户菜单、「添加 ▾」)。
8. **宽度各自为政**:侧栏 256、设置导航 220、账户弹层 310(比侧栏宽,压到主区)、定制中心内容 880、自动化内容 804。
9. **深色层次**:画布与侧栏 ≈1.03:1;弹层比画布暗。
10. 活稿之间的令牌漂移早有记录(`docs/design/README.md`「Known open decision: token drift」),本次不重复统计。

令牌提案(新增 5 支、改 3 支浅色值与 8 支深色值,其余不动)见 `frame.html#tokens`。
