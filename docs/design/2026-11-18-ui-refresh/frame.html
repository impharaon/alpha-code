新视觉方向：安静的中性色、一支强调色、一条发丝线

两张样张（新对话首页、定制中心）与五个组件帧，用于确认方向；获批后再并入各页活稿，不直接改实现。整页画框 1440×900，可切到 1280×800 看窄窗下的排布。浅色为主；应用有深色主题，只给首页出一张深色样张。

方向一句话：三列（窄轨 / 侧栏 / 主区）用三档中性灰分层，只用一条发丝线分隔；强调色只留给主要动作、焦点和当前运行权限；选中、悬停一律中性灰，不再用淡紫底。现状逐处问题见同目录 audit.md。

样张一 · 新对话首页 #home

最左窄轨放全局入口（新对话、搜索、定制中心、自动化，账户在底部）；侧栏只放品牌与项目（项目下是最近对话）；顶栏常驻，左上角是红绿灯、左栏开关与前进后退。主区去掉大水印和「新对话 — 项目名」，标题改为更大的「我们要处理什么？」。输入框底部一行：「+」、运行权限、模型与推理强度合并的一个按钮、发送；项目 / 文件 / 插件放在贴着输入框下沿的托盘里。

改动与理由

  • 版面：加 48px 窄轨放全局入口（owner I-02）；侧栏只留品牌与项目；侧栏「搜索」一行去掉（I-03），搜索在窄轨与 ⌘K，侧栏筛选收进「项目」标题右侧。
  • 顶栏常驻（I-09）：左上角左栏开关与前进后退在任何页面同一位置；主区顶栏写当前页面或「项目 / 对话」；右栏开关只在会话页顶栏右端一处。
  • 用色（I-01）：三档中性灰分三列，一条发丝线分隔；选中、悬停、焦点底一律中性灰；强调色只留给主要动作、焦点环、未读点和「全部批准」。深色拉开三列明度。
  • 首页（I-07）：去掉水印、发光、噪点和「新对话 — 项目名」，标题「我们要处理什么？」30px。
  • 输入框（I-04/05/06）：模型与推理强度合并为一个按钮和一张卡（分档滑条）；「+」菜单向下、单色图标、无淡紫；项目 / 文件 / 插件进贴着输入框的托盘。
  • 无项目（I-08）：左对齐的说明 + 行样式「打开项目」+ 默认工作区一句话。
  • 右栏（I-10）：同底色、文字页签、统一空状态，去掉重复的收起钮与终端按钮。
  • 定制中心（I-11/12）：顶级页面，替换主区；无外框两列列表、中性图标、「+」/「…」两种动作、状态小字；「添加 ▾」改中性按钮。
