成功无匹配臂
1. 让模型自然联网检索；保留 searchId、每个适用来源的真实状态及全部候选和语义选择理由。
   不要求候选列表为空：无关候选可以存在。不得删除能满足目标的现成候选来制造无匹配。
   若模型找到实际匹配，按现成匹配臂记录，本轮无匹配未覆盖；另选真实无匹配任务重放，
   保留原任务与原查询记录，不把匹配的现成能力改称不匹配。任何来源失败也不算无匹配成功。
2. 在全来源成功且确无匹配的轨迹中，检查先说下句，随即制作，不问第二次同意：
   在本次查询的来源中没有找到现成插件，正在为你制作一个自己的插件。
3. 检查 create 使用真实 searchId，files 草稿通过同一工具交 main，而非先落项目。
   留存 requestId/packageId、created 来源、自动开启和引擎实际可用事件。
4. 用刚装入的技能执行真实文件任务，结果应为「柚子=7|苹果=3」。保留读取/执行调用，
   只把模型回答相同文本而没使用实际新能力记失败。比较项目配置/文件树仍等于基线。
5. 在定制中心查看同一 packageId：来源「我的插件」、全项目生效范围、组件和真实状态。
   到项目乙检查同一 packageId/能力可用，不能另装第二份来通过。
6. 回甲用同一包的现有整包移除动作。确认图/组件记录、托管技能 generation 和活工具都撤回，
   系统助手本身仍在；再次比较甲乙配置原始字节不变。保存前后截图和只读身份投影。
