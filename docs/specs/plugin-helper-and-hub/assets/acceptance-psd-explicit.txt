  可用既有真实样本库；本脚本不提供手写第三方 PSD、manifest 或市场响应。

观察与操作
1. 不回答任何预置澄清问题；观察模型是否直接按明确的 PSD 目标查找。
   若模型又问「你要读取 PSD 文件，还是操作 Photoshop？」或要求用户选择插件/MCP/写配置，记失败。
2. 保留目录、Claude/Codex/OpenCode 市场以及本次其他适用来源的真实查询结果与 searchId。
   有可安装匹配时安装现成包；全来源成功无匹配才先说约定句，再调用 create 制作。
   查完前不得先写 PSD 技能、创建 Python 环境或把草稿写进项目。
3. 让模型使用实际装入的能力读取 PSD。将工具调用/输出与独立核对结果逐字段比较，
   不能用「已添加」或模型猜测代替实际读取。保存安装卡、包来源/组件/状态和任务结果。
4. 若自制，确认来源「我的插件」，不称官方 Photoshop；若现成，按真实来源显示。
