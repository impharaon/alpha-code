# 用户可在安全边界内连接自己的远程数据库

用户可在安全边界内连接自己的远程数据库。这份规格保留已提出的结果及其证据，让使用者能区分已具备的能力与仍需补齐的部分。尚未做过的实机验证不会被写成通过。

## 用户与范围

- 用户：想让 Code Puppy 直接查询自己公司 PostgreSQL、MySQL 的桌面用户。
- 核心路径：在定制中心打开数据库连接器 → 填数据库地址、端口、账号 → 确认「允许连接到这个地址」→ 对话里让助手查库，拿到真实结果。
- 包括：PostgreSQL 与 MySQL 两种远程数据库的只读查询；用户逐个地址明确放行；放行随连接器的修改与卸载撤销。
- **不包括**：写入、改表、删数据；通用的出网放行框架；放宽现有围栏的默认值；其他数据库种类；Windows 与 Linux（见范围取舍）。
- 假设与依赖：在 OpenCode 2 换代（alpha-code#1662）合入之后实施；本机 SQLite 连接器已交付（SPEC-official-readonly-connectors），本规格在它之上扩展。实现前须有已批准的技术方案（见待决第 2 条）。
- 范围取舍：本期必做 = macOS 上的 BR-01 至 BR-05。Windows、Linux 后续考虑（原票要求方案说明两者现状，不承诺本期交付）。写入能力不采纳 —— 现有数据库连接器是只读的，保持一致。

## 体验约定

- 用户路径：见核心路径。
- 交互与状态：复用定制中心现有的连接器安装与配置窗口（与 GitHub 连接器填 token 的窗口同一套）；新增地址、端口、数据库名、账号、密码字段和一句放行确认。连接失败时在窗口内显示原因（地址不通、账号不对、未放行）。
- 文案：放行确认「允许这个连接器连接到 <地址>:<端口>。它不能连接其他地址。」
- 设计稿：复用现有连接器配置窗口的字段样式；属于现有组件内加字段，不另出稿。若方案阶段发现需要新的窗口结构，回到本规格补稿。

## 业务规则

- **BR-01 只连用户放行的地址**：数据库连接器只能连接用户在配置窗口里填写并确认的那一个「地址:端口」；其他地址和端口照旧被围栏拒绝 —— INT-safety/I-08，原票「不放松围栏」。
- **BR-02 只有用户本人能放行**：放行只能由用户在配置窗口里操作产生；模型、项目文档、其他扩展都不能新增或修改放行的地址 —— 原票「如何防止模型或项目配置借此打开任意出网」。
- **BR-03 放行跟着连接器走**：用户改了地址则旧地址立即失效；卸载或停用连接器后该地址不再可连 —— 原票「放行记录的生命周期」。
- **BR-04 只读**：查询可以执行，写入、改表、删除被拒绝并说明原因 —— 与 SPEC-official-readonly-connectors BR-02 一致。
- **BR-05 密码不落明文**：数据库密码按现有连接器密钥的保存方式存放，不写进项目文件、日志和对话内容 —— 现有密钥保管规则。

## 用户会碰到的限制

| 用户碰到什么 | 多做、多懂什么 | 用户能接受吗 | 换来什么 | 出处 |
| --- | --- | --- | --- | --- |
| 每个数据库地址要单独填写并确认一次 | 换库或换端口要回到配置窗口改 | 可以：一次配置长期有效 | 连接器和借它出网的任何东西都到不了别的地址 | 原票「不放松围栏」 |
| 不能通过对话让助手写库 | 写入要用自己的工具 | 可以：与本机 SQLite 连接器一致 | 助手出错不会改坏公司数据 | BR-04 |

## 验收

| ID | Given / When / Then | 依据 |
| --- | --- | --- |
| AC-01 | 给定用户在配置窗口填了一个真实 PostgreSQL 的地址并确认放行；当对话里让助手执行 `SELECT 1`；则返回真实结果 | BR-01 |
| AC-02 | 同 AC-01，数据库换成真实 MySQL | BR-01 |
| AC-03 | 给定已放行地址 A；当连接器（或经它发起的任何连接）尝试连接另一个地址 B 或 A 的另一个端口；则连接被拒绝，对话里看到明确的「未放行」原因 | BR-01 |
| AC-04 | 给定项目文档或模型的工具调用里带了一个新的数据库地址；则该地址不会被放行，连接被拒绝 | BR-02 |
| AC-05 | 给定用户把地址从 A 改成 B，或卸载了连接器；则 A 立即不可连 | BR-03 |
| AC-06 | 给定已连上的数据库；当助手执行写入或改表语句；则被拒绝并说明连接器只读，数据库无变化 | BR-04 |
| AC-07 | 配置完成后，项目文件、应用日志和对话记录里搜不到数据库密码 | BR-05 |
| AC-08 | 未安装或未配置数据库连接器时，其他扩展的出网行为与改动前完全一致 | BR-01 |

原 AC-01 草案已由上表取代（编号沿用）。
