# SPEC-remote-database-connector｜用户放行的地址,连接器可以连

连接器自己会连数据库、会查询。Code Puppy 作为平台只负责四件事:装卸连接器、保管密钥、调用前按权限询问、用安全围栏限制它能访问的网络和文件。前三件已经有了;问题出在第四件:围栏只放行走出网代理的网页请求,数据库这类直接连接一律被拦,而且没有任何放行的办法。本规格补上这个办法:用户自己点头的地址放行,其余照旧拦住。

文件名与编号沿用原需求(「连接自己的远程数据库」);v2 起按平台能力重写,见批准记录。

## 用户与范围
- 用户:装了某个需要直接网络连接的连接器的桌面用户。第一个场景:用数据库连接器查自己公司的 PostgreSQL 或 MySQL。
- 核心路径:在连接器窗口填地址和端口 → 确认「允许连接」→ 连接器连得上这个地址。
- 包括:用户逐个地址放行;放行只对填写的「地址:端口」生效;放行随连接器的修改、停用、卸载撤销;沿用现有的连接器密钥保管。
- **不包括**:连接器自己的功能(查什么、只读还是可写、支持哪种数据库 —— 由连接器决定,平台不替它做);通用的出网策略配置界面;放宽围栏的默认值;Windows 与 Linux(后续考虑)。
- 假设与依赖:在 OpenCode 2 换代后的 `alpha` 上做;实现前须有批准的技术方案(涉及安全围栏)。
- 范围取舍:本期必做 = BR-01 至 BR-05。v1 里的「只做 PostgreSQL 与 MySQL」「只读」两条删除(那是连接器的事,见上);「只做 macOS」保留。

## 体验约定
- 用户路径:见核心路径。
- 交互与状态:复用现有连接器配置窗口,加地址、端口字段和一行确认。
- 文案:确认行「允许连接 `<地址>:<端口>`」;小字「建议使用只读账号」(仅数据库类连接器显示)。连不上时各一句:「地址连不上」「账号或密码不对」「还没有允许连接这个地址」。
- 设计稿:复用现有连接器配置窗口的字段样式,属于现有组件内加字段,不另出稿。

## 业务规则
- **BR-01 放行的才能连**:连接器的直接网络连接只能到达用户在窗口里放行的「地址:端口」;没放行的地址和端口照旧被拦 —— I-08;「不放宽围栏的默认值」。
- **BR-02 只有用户本人能放行**:放行只由用户在连接器窗口里的操作产生;模型、项目文档、其他扩展都不能新增或修改放行的地址 —— 原票「防止模型或项目配置借此打开任意出网」。
- **BR-03 放行跟着连接器走**:改了地址则旧地址立即失效;停用或卸载连接器后该地址不再可连,已建立的连接一并断开 —— 原票「放行记录的生命周期」。
- **BR-04 如实告知范围**:放行之后,同一个「地址:端口」对助手执行的命令和其他扩展同样可达;界面与文案不作「只有这个连接器能连」的承诺 —— owner 2026-11-13「不要限制的太死」;技术上做不到按连接器隔离(系统沙箱不认具体地址,方案走出网代理)。
- **BR-05 密码不落明文**:连接器的密码按现有连接器密钥的保存方式存放,不写进项目文件、应用日志和对话内容 —— 现有密钥保管规则。

| --- | --- | --- | --- | --- |
| 每个地址要填写并确认一次 | 换库或换端口要回到窗口改 | 可以:一次配置长期有效 | 没放行的地址谁也连不上 | BR-01 |

## 验收
| ID | Given / When / Then | 依据 |
| --- | --- | --- |
| AC-01 | 给定用户在数据库连接器窗口填了一个真实 PostgreSQL 的地址并确认;当对话里让助手查一条数据;则返回真实结果 | BR-01 |
| AC-02 | 同 AC-01,换成真实 MySQL | BR-01 |
| AC-03 | 给定已放行地址 A;当任何进程尝试直接连接另一个地址 B,或 A 的另一个端口;则连接被拒绝,对话里看到「还没有允许连接这个地址」 | BR-01 |
| AC-04 | 给定项目文档或模型的工具调用里带了一个新地址;则它不会被放行,连接被拒绝 | BR-02 |
| AC-05 | 给定用户把地址从 A 改成 B,或停用、卸载了连接器;则 A 立即不可连,已建立的连接被断开 | BR-03 |
| AC-06 | 确认窗口与提示里没有「只有这个连接器能连」「不能连接其他地址」这类说法 | BR-04 |
| AC-07 | 配置完成后,项目文件、应用日志和对话记录里搜不到连接器的密码 | BR-05 |
| AC-08 | 没有任何连接器放行地址时,所有扩展的出网行为与改动前完全一致 | BR-01 |

v1 的 AC-06(写入被拒)删除:只读与否由连接器自己保证,不是平台的验收。编号 AC-06 由上表新条目接替,删除原因见本段。
