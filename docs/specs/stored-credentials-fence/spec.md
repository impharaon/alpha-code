# 对话里的命令和工具读不到、改不了本机存的密钥

## 来源

- 意图：impharaon/alpha-work `docs/intents/INT-safety.md` I-20（owner 原话 U-16，2026-11-19）。编排器给 owner 的建议原文：「密钥只留在应用主进程里，用到时由主进程代办，围栏内的进程一律读不到这个目录。这样用户完全无感，但要先出技术方案。」owner 的回答（逐字）：「按照你的建议，不要设计的过于复杂。」
- 发现依据（2026-11-19，真引擎 + 生产围栏 profile + 假密钥）：「全部批准」档里一条 `cat` 不经询问就读到 `<userData>/codepuppy-secrets/` 下的值；「请求审批」档一次普通命令审批后读到；会话还能追加写、替换、删除、硬链、克隆这些文件。原因：进程围栏只限制写入与联网。
- 技术设计：[DESIGN stored-credentials-fence](design.md)（三轮 Codex 方案审查；编排器裁决 D9、D10）。

## 用户与范围

- 用户：使用 Code Puppy 桌面端的用户。本规格没有任何用户可见的变化：不新增步骤、提示、等待或设置。
- 包括：Code Puppy 自己的凭据存放点（登录凭据、用户填写的模型密钥、云连接器令牌、连接器令牌，以及官方连接器运行期的明文目录）。
- 不包括：
  - 对话改写围栏内可写的引擎配置，从而改变一份被合法代入的凭据被送到哪里（换掉连接器的命令、覆盖模型的 `package`，以及任何同类做法）。这一类由 INT-safety I-13（引擎配置在围栏内不可写）关闭，另行设计与交付。
  - 本规格安装之前，某次对话已经做出的硬链、克隆或拷贝：那是既有暴露，改规则收不回已经离开原文件的值（设计 D9）。
  - 第三方远程连接器自行登录后存在引擎数据库里的令牌；连接器子进程在自己环境里合法拿到的值；引擎进程内存；用户自己选择加载的进程内插件；Code Puppy 存放点之外的任何位置。

## 业务规则

- **BR-01** 被围栏的进程树里，任何进程都读不到、拷不走、挪不走、改不了 Code Puppy 存在本机的凭据文件。
- **BR-02** 引擎与 ext 拿到的凭据值只来自内存里的一张表；引擎每次装载配置之前向主进程取一次这张表；出错、超时、通道关闭时不用旧表，走既有的恢复路径。
- **BR-03** 指向凭据存放点的引用只在封闭清单的凭据位置被代入；在其它任何位置按普通读取处理，被拒绝。
- **BR-04** 主进程不替一个经别名（软链、相对路径、大小写变体、firmlink 写法）指向凭据文件的引用去读它。
- **BR-05** 模型调用、连接器调用、登录与续期、运行中添加或删除密钥照常工作；升级后已存的密钥与登录状态继续可用。

## 验收

| ID | Given / When / Then | 依据 |
| --- | --- | --- |
| AC-01 | Given 真引擎、生产围栏 profile、存放点里的假凭据；When 在「全部批准」「请求审批」「只读」三档里，用 shell 命令与读文件工具，以直接路径、大小写变体、`/.vol` 写法、工作区里新建的软链、硬链、克隆去读，以及覆盖写、改名、删除、把上级目录改名搬走；Then 全部被拒，假值不出现在交给模型的任何结果里，事后在围栏外核对文件原样。<br>*拿什么证明*：真引擎三档用例；对照臂（去掉规则）必须读到。 | BR-01 |
| AC-02 | Given 同上；When 模型请求、连接器调用、登录续期、运行中新增与删除一把模型密钥、启用与停用一个带令牌的连接器；Then 都成功，引擎进程没有从磁盘读任何凭据文件；续期或新增之后的下一次请求带的是新值。<br>*拿什么证明*：真引擎用例；「只加规则、不换读法」的对照臂必须以具名错误失败。 | BR-02、BR-05 |
| AC-03 | Given 对话把一个指向凭据存放点的引用写进围栏内可写的配置里、位置不在封闭清单内（例如某个智能体的系统提示）；When 配置重新装载并发起模型请求；Then 请求里没有凭据值。<br>*拿什么证明*：真引擎用例；把代入范围放宽为全文的对照臂必须泄漏。 | BR-03 |
| AC-04 | Given 对话在工作区里放一个指向凭据文件的软链，并让某个连接器条目引用它；When 用户在设置里启用该连接器（主进程直接应用路径）；Then 主进程不读取该文件，值不出现在连接器的配置里。<br>*拿什么证明*：经真实主进程应用路径的用例，覆盖软链、相对路径、大小写变体、firmlink 四种写法。 | BR-04 |
| AC-05 | Given 主进程迟迟不应答或通道关闭；When 引擎装载配置；Then 这次装载不使用旧表，进入既有恢复路径，恢复后凭据位置取到当前值；用户不需要重装或重启。<br>*拿什么证明*：延迟应答与超时两条用例。 | BR-02 |
