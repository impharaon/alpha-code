--------------------------------------------------------------------------------

Full licenses, attribution and ONNX Runtime third-party notices for sherpa-onnx,
Whisper / OpenAI, whisper.cpp, whisper.node, Silero VAD, pyannote segmentation,
3D-Speaker, FFmpeg (LGPL 2.1), OpenH264, libdav1d (BSD-2-Clause; VideoLAN and dav1d authors), Tesseract, tessdata_fast, Leptonica,

FFmpeg is built without GPL/nonfree libraries and uses OpenH264 for H.264
and libdav1d for software AV1 decoding.
The downloaded ffmpeg component includes its licenses and SOURCE.json. The
matching source release asset named there includes the original source
archives and locked build tools, the build configuration and BUILD.sh. Sources accompany each
platform's binary asset on the same public release.
