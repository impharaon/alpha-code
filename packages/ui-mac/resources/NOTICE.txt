Bundled document and design skills
--------------------------------------------------------------------------------
The seven Anthropic skills docx, xlsx, pptx, pdf, frontend-design, canvas-design
and theme-factory are adapted under factory-skills/office-docs/ and licensed
under Apache-2.0. Each directory retains its complete LICENSE.txt. Upstream:
https://github.com/anthropics/skills/tree/e4bb5d960d87126ff3b3a8af1a104b7db67560ba/skills
Adapted by Code Puppy, 2026-11-26: local runtime paths, Chinese typography,
template priority, local rendering and one-round visual review. The accompanying
factory-skills/office-docs/document-skills.lock.json records every source hash,
shipped hash, modification and exclusion. External standards XSDs, upstream
canvas-fonts and theme-showcase.pdf are not distributed.

Bundled document production assets
--------------------------------------------------------------------------------
Office Python (CPython 3.11.15) and its pinned document libraries are under
office-runtime/. Their original licences remain in the Python distribution,
site-packages/*.dist-info/licenses/ (including PDFium and its
third-party notices). Python dependency versions/hashes are recorded by the
Office runtime build locks. No package installer is required at runtime.

Document JavaScript libraries docx 9.16.0 and PptxGenJS 4.0.1, and their locked
dependencies, retain their original LICENSE/NOTICE files in
document-assets/node_modules/. The asset inventory records shipped hashes.

Noto Sans SC: © 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name
'Source'. Noto Serif SC: © 2017-2024 Adobe (http://www.adobe.com/). Both are
licensed under SIL Open Font License 1.1. Full licences, copyrights, fixed source identity
and Code Puppy static-font modification details ship in document-assets/licenses/.
Chinese Office templates are application-authored; their source/version are
recorded in each template's custom properties.

Local video and audio components
--------------------------------------------------------------------------------
SenseVoiceSmall (FunASR / Alibaba) model and its complete Model License 1.1
are included at video-mcp/licenses/SenseVoiceSmall.txt. The original model
archive carries a link to this text; that link is not a replacement for it.

Full licenses, attribution and ONNX Runtime third-party notices for sherpa-onnx,
Whisper / OpenAI, whisper.cpp, whisper.node, Silero VAD, pyannote segmentation,
3D-Speaker, FFmpeg (LGPL 2.1), OpenH264, Tesseract, tessdata_fast, Leptonica,
libjpeg-turbo / IJG, yt-dlp and its EJS helper ship in video-mcp/licenses/.
video-mcp/licenses.json records each original source and the full text digest.

FFmpeg is built without GPL/nonfree libraries and uses OpenH264 for H.264.
The downloaded ffmpeg component includes its licenses and SOURCE.json. The
matching source release asset named there includes both original source
archives, the build configuration and BUILD.sh. Sources accompany each
platform's binary asset on the same public release.
